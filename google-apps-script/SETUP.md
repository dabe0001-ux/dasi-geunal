# Google Sheets 문의 접수 연결

이 폴더의 `Code.gs`는 홈페이지 문의를 Google Sheets에 저장하고 `dabe0001@naver.com`으로 새 문의 알림을 보내는 Apps Script입니다.

## 1. 접수용 시트 만들기

1. Google Sheets에서 새 스프레드시트를 만듭니다.
2. 메뉴에서 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 코드를 지우고 `Code.gs` 내용을 붙여넣습니다.
4. 프로젝트 설정에서 시간대를 `Asia/Seoul`로 지정합니다.
5. 함수 목록에서 `setupSheet`를 한 번 실행하고 권한을 승인합니다.

## 2. 웹 앱 배포

1. Apps Script 우측 상단의 **배포 → 새 배포**를 누릅니다.
2. 유형은 **웹 앱**을 선택합니다.
3. 실행 계정은 **나**, 액세스 권한은 **모든 사용자**로 설정합니다.
4. 배포 후 발급된 `/exec` 주소를 복사합니다.

## 3. 홈페이지 연결

`index.html`에서 아래 값을 찾아 `/exec` 주소를 입력합니다.

```js
var GOOGLE_APPS_SCRIPT_URL = 'https://script.google.com/macros/s/발급값/exec';
```

URL이 비어 있으면 홈페이지는 자동으로 `dabe0001@naver.com` 이메일 문의 방식으로 작동합니다.

## 4. 배포 전 확인

- 테스트 문의가 시트의 `문의` 탭에 저장되는지 확인합니다.
- `dabe0001@naver.com`으로 알림 메일이 오는지 확인합니다.
- 시트 공유 권한은 소유자만 접근하도록 유지합니다.
- 실제 문의에는 연락처와 이메일이 포함되므로 시트를 공개 링크로 공유하지 않습니다.
- 사진 파일은 홈페이지에서 저장하지 않습니다. 1차 상담 후 이메일 또는 별도 안전한 채널로 받습니다.
